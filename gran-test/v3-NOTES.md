# v3 — ритм сетки, не новый сюжет

Основной макет не менялся. v2-блок «Срез» сюда не входил.

Те же секции ТЗ. Другой рисунок.

| Секция | Что сделано | Как близко к KIT |
|---|---|---|
| Слайдшоу 1 | Текст сверху слева + вертикальная подпись по краю. Низ скошен в бумагу. | Текст: выравнивание слева-сверху. Скос — в самой картинке слайда. |
| Коллекции 1 | Не 2×2. Широкая / две узкие / широкая. Фаска угла, кольцо в центре. | Нативно — один размер карточки. Ритм 1+2+1 собирается **двумя рядами** или одной составной картинкой на широкие. |
| Полка 1 | Bento: высокая + две + широкая. | Близко к «лента» + акцент первой. Идеальная bento в KIT нет — это целевой вид. |
| Слайдшоу 2 | Скос сверху, рельс справа, текст снизу. | Те же настройки слайда, зеркало. |
| Коллекции 2 | Широкая «Готовые», узкая «На заказ» с нахлёстом. | Две карточки, разные пропорции фото (2:1 и 1:1), если секция позволяет один ratio — узкая кропается внутри 2:1. |
| Полка 2 | Лента, четвёртая выглядывает. | Прямой режим KIT «лента / карусель». |

Фаска — система «грани»: срезан угол кадра, не кольцо.
