## Что внутри

| Файл | Подача |

## Просмотр

```bash
cd outreach/migrapro-test
python3 -m http.server 8765
# A: http://127.0.0.1:8765/
# B: http://127.0.0.1:8765/variant-b.html
# C: http://127.0.0.1:8765/variant-c.html
```

## Как отдать в Figma (обязательный формат теста)

1. Создайте файл в Figma: фреймы `Desktop 1440` и `Mobile 390`.
2. Установите плагин **html.to.design** (или **html → design**).
3. Import → URL `http://127.0.0.1:8765/` (или задеплойте на Vercel/Netlify и дайте публичный URL).
4. Разложите результат по фреймам Desktop / Mobile, проверьте автолейаут и отступы.
5. Ссылка «Anyone with the link → can view» — отправьте Дарье.

Альтернатива без плагина: откройте макет в браузере на 1440 и 390, сделайте full-page скрины и соберите фреймы вручную по сетке 8px / контейтеру Inter.
