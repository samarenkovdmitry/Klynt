# ГРАНЬ — тестовое задание (Яндекс Крауд / KIT)

Интернет-магазин мастерской серебряных колец. Макеты собраны под секции конструктора Яндекс KIT.

## Состав

| Файл | Что это |
|---|---|
| [index.html](index.html) | Обложка файла, навигация по фреймам |
| [desktop-wireframe.html](desktop-wireframe.html) | Главная, desktop **1920**, только структура |
| [mobile-home.html](mobile-home.html) | Главная, mobile **390**, визуал к запуску |
| [PROCESS.md](PROCESS.md) | Разбор брифа, логика блоков, работа с ИИ |
| [exports/](exports/) | PNG фреймов для просмотра и переноса в Figma |
| [assets/logo.svg](assets/logo.svg) | Знак |

## Как смотреть

1. Откройте `index.html` или сразу два фрейма.
2. Desktop: ширина страницы 1920, контент 1440.
3. Mobile: ширина 390.

Ссылку на Figma из этой среды выложить нельзя: исходник — HTML-фреймы точного размера + PNG. Их можно вставить в выданный Figma-файл в рабочие области 1920 и 390.

## Тема KIT (чтобы перенести 1:1)

- Бренд: `#1A1814`
- Фон / текст: `#E9E1D2` / `#1A1814`
- Поля: desktop content 1440 (уши) или 144px; mobile 16px
- Фото товара: **3:4**
- Скругление: 2
- Шрифты: Unbounded (заголовки), Manrope (текст)
- Слайдшоу: 5:2 desktop, 4:3 mobile
